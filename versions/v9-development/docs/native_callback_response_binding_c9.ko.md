# Native 응답 영수증과 보고서 이름 보존

새 점수 생성 시 `_score_arm`은 원 native 콜백의 `arm-response.json` 경로, 파일 SHA와 파싱된 값의 SHA를 증거에 저장한다. 콜백이 반환한 출력과 원 파일의 모든 측정·설정·선택·trace·보고서 경로 필드는 정확히 같아야 한다. 원 파일을 쓰지 않는 사용자 정의 콜백은 실제 비교 점수 조건을 충족하지 못한다.

기존 두 native 콜백의 캐시 재개에는 `resumed_without_execution`과 `independent_review_pending` 두 bool 표시가 추가되거나 갱신된다. 이 두 표시만 파일과 반환값 대조에서 제외하며, 존재하면 정확한 bool이어야 한다. 원 파일을 다시 쓰거나 보고서 경로를 바꾸는 것은 허용하지 않는다.

저장된 점수 재검증은 같은 native 경로와 원 파일 SHA를 먼저 확인한다. 의미 검토가 pending이고 `audits=[]`여도 같은 내용의 다른 companion 경로로 응답만 바꾸면 원 영수증 해시가 맞지 않아 거부한다. 원 두 보고서 숫자·의미 검토와 충분성 재계산은 별도 필수 조건으로 유지한다.

공학 검사는 합성 파일만 사용하며 원 CPU·모델·owner 단계는 실행하지 않는다. 보고서 검증과 원 파일 해시 대조는 실제 함수다. 점수 전체와 외부 증거 핀까지 권한 있는 host가 함께 다시 쓰는 행위를 이 파일 해시만으로 인증할 수 있다는 주장은 하지 않는다. 원 증거를 보존하는 host 책임과 독립 실행·평가 역할은 그대로 필요하다.
