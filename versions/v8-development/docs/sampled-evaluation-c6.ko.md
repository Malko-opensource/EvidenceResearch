# 비공개 샘플링과 최종 비교 계약

이 개발 후보는 기존 고정 다항식 과제에서 발견한 검증 문제를 수정한다. 기존
v4/v5 실행과 판정은 원 기준으로 보존한다. 현재 코드 검사나 과제 생성은 실제
연구 성능의 향상 또는 최종 평가 완료를 증명하지 않는다.

개발과 최종 과제는 degree 2/3/4/5, 계수 U[-1.4,1.4], noise U[.08,.5],
train 수 40/64/96의 같은 명시된 법칙에서 생성한다. 기본 owner 생성 seed는
비공개 256-bit 값이다. 각 과제의 train/validation/test 난수도 서로 다른 비공개
256-bit 값이다. 공개 seed는 식별값이며 숨긴 test 난수를 재생하지 않는다.
계수, 잡음 규모, owner 난수와 test 행은 참가자 요청에 포함하지 않는다.
공개된 데이터로 통계적 예측이 가능한 것과 숨긴 정답을 직접 복원하는 것은 구분한다.
이는 요청·도구 경계이며 운영체제 전체의 파일 읽기 격리를 보증하지 않는다.

등록자는 private 설정에서 실제 RNG draw 순서를 다시 생성하여 정의, 식별값,
분할 난수와 digest를 대조한다. 법칙 안에서 계수를 바꾸고 hash를 다시 계산해도
거부한다. 최종 public 객체는 허용된 정확한 schema로 재구성해 비교하여 추가
owner 필드를 넣은 fresh-hash 파일도 거부한다. 최종 count와 순서는 private
생성 영수증, suite, design 모두와 일치해야 한다. 등록 파일은 생성 후 변경하지 않는다.

초기 개발 수는 분산의 상대 표준오차 목표 .5에 대한 정규 근사
ceil(2/.5²)+1=9에서 정한다. 이는 계획 가정이며 실제 효과 분포의 정규성,
충분한 검정력 또는 모집단 분산 상한을 보증하지 않는다. 연구 루프의 횟수·시간·
연속 실패 제한도 아니다. 실패나 보류 결과를 버려서 유리한 분산을 만들지 않는다.
불완전한 개발 결과로 이 버전의 최종 샘플 계획을 인증할 수 없다.

upstream_adaptation의 최종 등록은 이 버전에서 독립 판정까지 완료한 개발
pilot-registration.json을 요구한다. package source 19개, external-fixed
upstream manifest와 원본 35개, 같은 전체 baseline provenance·모델·자원·분포를
대조한다. 실제 owner score를 다시 검증하고 paired token gain과 log test-MSE
ratio를 재계산하여 설계 입력과 정확히 비교한다. 이전 과제 정의는 모두 제외한다.
등록 후 해당 개발 판정의 hash도 동결한다. 이전 버전 분산이나 자기평가만으로
새 최종 평가를 등록할 수 없다.

계획한 효율 채택 기준은 paired95% provider-token 감소 구간의 하한 >20%와
test-MSE 비열등성 log ratio 구간의 상한 <log(1.10)을 모두 만족하는 것이다.
본문·companion 모두의 공통 내용, 독립 수치·의미 inventory 완료와 unsupported
claim 0, 실제 모델/CPU 증거, 모든 쌍이 필요하다. 비용의 금액이 알려지지 않으면
null이며 token 수로 가격을 추정하지 않는다. 개발 결과는 채택이 아니다.

B/C는 gpt-6.1-sol/medium과 같은 CPU·문헌·도구·요청 자원으로 비교한다.
모델 내부 sampling seed나 서버 weight 버전은 알려지지 않는다. A의 원 연구
모델 계열은 현재 전송 경계에서 미실행이므로 모델 교체 효과는 미측정이다.
여러 설계 요소를 함께 바꾸는 B/C는 프레임워크 묶음의 효과이며 개별 메커니즘의
원인을 분리하지 못한다. 기능적 기억 재사용과 인과적 성능 향상도 구분한다.

재현에는 `pilot-sample-config`, `pilot-register`, `pilot-run`을 사용한다. 완료된
응답과 실험은 재실행하지 않고 hash·고정 verifier·독립 판정을 재확인한다.
final suite를 만들고 등록하는 작업은 개발 판정 완료 후 별도 owner 작업이다.
최종 결과를 보고 수정하면 해당 과제는 개발로 전환하고 새 최종 과제를 사용한다.
