## Fitting and Evaluation

The trusted host performs polynomial feature construction, preprocessing, coefficient fitting, and evaluation. Coefficients are fitted using training observations only.

A degree-\(d\) predictor has the polynomial representation

\[
f_d(x)=\beta_0+\sum_{j=1}^{d}\beta_jx^j.
\]

The host’s feature scaling, intercept treatment, solver, and objective normalization are not established by the supplied execution record. Accordingly, `alpha` denotes the host’s penalty parameter without assuming a particular mathematical normalization.

Evaluation uses unpenalized mean squared prediction error:

\[
\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}
\left(y_i-\widehat f(x_i)\right)^2.
\]

Validation MSE is the sole selection criterion. Selection considers only distinct configurations with successfully reported measurements:

1. Choose the lowest validation MSE.
2. Resolve exact ties by lower degree.
3. Resolve remaining exact ties by lower penalty.

Rounded display values do not define ties.

Planned comparisons assess degrees at a common penalty and penalties within a common degree. Each comparison requires measurements for both candidates. Equal numerical penalties across degrees do not guarantee equal effective shrinkage because the feature matrices differ.

## Interpretation and Limitations

The verified quadratic result provides a reference measurement. Current evidence cannot determine whether linear models underfit, higher-degree terms help, or positive regularization improves prediction.

Evaluation uses one fixed validation split. Aggregate MSE values alone do not provide uncertainty estimates, confidence intervals, or significance tests. Selecting among candidates using these validation observations may make the selected validation error optimistic as an estimate of future prediction risk.

No hidden test performance, baseline improvement, timing comparison, hardware specification, memory measurement, or monetary cost is supplied.
