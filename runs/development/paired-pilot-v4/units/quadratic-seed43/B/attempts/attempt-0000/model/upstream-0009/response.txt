Polynomial regression provides a controlled setting for studying how model flexibility and coefficient shrinkage affect predictive error, but their relative benefits require measured comparisons rather than assumptions about visible curvature. We investigate this question using a preregistered polynomial ridge regression protocol on a fixed seed-43 dataset containing 80 training observations and 64 validation observations. The protocol fits candidates exclusively on training data through the host implementation, preserves existing preprocessing, and selects the evaluated configuration with the lowest validation mean squared error (MSE), resolving exact ties by lower polynomial degree and then lower regularization strength. The planned comparison examines an unregularized quadratic alongside seven configurations spanning polynomial degrees from 1 to 8 and regularization strengths from 0.1 to 10.0. Available execution evidence covers only the initial candidate, degree \(d=2\) with penalty parameter \(\alpha=0.0\), which is an unregularized quadratic fit. This candidate achieved training MSE \(0.008910787936555437\) and validation MSE \(0.008575589501453651\), with host-reported valid independent verification. The host records two actual CPU attempts and one distinct evaluated configuration; these counts do not provide independent statistical replications. The observed errors are consistent with the quadratic transferring well to this validation split, but they do not establish that quadratic curvature is necessary, that higher-degree models overfit, or that regularization is ineffective. We therefore retain \(d=2,\alpha=0.0\) provisionally as best among the single evaluated configuration. This report contributes a reproducible comparison protocol and a verified baseline measurement, while leaving the curvature-versus-shrinkage hypothesis unresolved. The remaining comparisons are proposed experiments, statistical uncertainty is unavailable, and test performance is withheld. Any subsequent selection using the same validation split must account for possible optimism in the selected validation error.
