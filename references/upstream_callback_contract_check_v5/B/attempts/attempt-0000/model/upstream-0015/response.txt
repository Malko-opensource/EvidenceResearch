The permitted model family comprises polynomial regression with degree \(d\in\{1,\ldots,8\}\) and ridge regularization strength \(\alpha\in[0,100]\). f_{d}(x)=b+\sum_{k=1}^{d}\beta_k x^k,

\]
where \(b\) is an intercept and \(\beta_k\) is the coefficient associated with the \(k\)-th power of the input. This representation is nonlinear in \(x\), but linear in its fitted parameters. Ridge regression augments squared-error fitting with a quadratic coefficient penalty. Under the conventional choice of an unpenalized intercept and an unnormalized sum of squared residuals, its objective is
\[
(\widehat b,\widehat{\boldsymbol{\beta}})
\in
\mathop{\mathrm{arg\,min}}_{b,\boldsymbol{\beta}}
\left\{
\sum_{i=1}^{80}
\left[y_i-b-\phi_d(x_i)^{\mathsf T}\boldsymbol{\beta}\right]^2
+
\alpha\sum_{k=1}^{d}\beta_k^2
\right\}.
\]
This equation explains the estimator family; it does not independently document the host's intercept, normalization, or feature-scaling conventions. The experiments retain the host implementation, and those conventions should be established from its implementation records before reproducing the fit elsewhere. For a design matrix \(X\) and response vector \(\boldsymbol y\) centered to accommodate an unpenalized intercept, the conventional ridge solution satisfies
\[
\widehat{\boldsymbol{\beta}}
=
(X^{\mathsf T}X+\alpha I_d)^{-1}X^{\mathsf T}\boldsymbol y,
\]
provided the indicated matrix is invertible. Here \(I_d\) denotes the \(d\)-dimensional identity matrix. Positive \(\alpha\) makes this matrix invertible under this formulation; at \(\alpha=0\), invertibility requires full column rank, with a least-squares solution otherwise defined through an appropriate generalized inverse. Zero regularization removes the coefficient penalty and recovers ordinary least-squares fitting within the chosen polynomial feature space. Positive regularization changes the fitted solution by penalizing coefficient magnitude. Consequently, evaluating a configuration with \(\alpha=0\) provides evidence about an unpenalized polynomial fit, without demonstrating whether positive regularization would improve prediction.

The relationship between polynomial degree and regularization follows from the geometry of the design matrix. Polynomial features derived from the same scalar input can be correlated, and their magnitudes depend on the input range and the powers included. Adding a feature therefore changes both the available prediction functions and the covariance structure relevant to coefficient estimation. For the conventional ridge formulation, if \(X=USV^{\mathsf T}\) is a singular value decomposition with positive singular values \(s_r\), the contribution along each corresponding coefficient direction contains the factor
\[
\frac{s_r}{s_r^2+\alpha},
\]
rather than the unpenalized factor \(1/s_r\). Equivalently, its fitted-response component is multiplied by \(s_r^2/(s_r^2+\alpha)\). These expressions explain how ridge regularization attenuates directions with small singular values, which may otherwise be sensitive to changes in the observed responses. They also explain why the same numerical regularization strength need not have the same effect at different polynomial degrees. Feature rescaling changes coefficient magnitudes and the associated penalty, so numerical values of \(\alpha\) are meaningful only together with the fitting conventions.
