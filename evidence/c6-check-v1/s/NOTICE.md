# 출처와 라이선스

Agent Laboratory의 원본 구현은 Samuel Schmidgall의 MIT 라이선스다. 고정 버전과
취득 해시는 `references/manifest.json`에 있으며, 원본 저작권과 허가 문구는
`references/AgentLaboratory.LICENSE`에 바이트 그대로 보존했다. 공개 실행 기록에는
원본 프레임워크의 프롬프트가 포함될 수 있다. 원본 소스는 취득 도구로 별도 받는다.

Agent Laboratory와 AgentRxiv 논문의 관찰은 문헌 주장으로 구분하고 원문 링크와
버전을 `docs/sources.md`에 남겼다. 논문·업스트림 코드의 저자나 성능을 이 프로젝트의
독립 실행 결과로 표시하지 않는다. 자체 구현은 루트 `LICENSE`를 따른다.
