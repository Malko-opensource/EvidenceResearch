# 현재 B 설정의 비교 해석 범위

이 문서는 진행 중인 paired-pilot-v4를 변경하지 않은 읽기 전용 검토다. 고정 소스는 46580f975fe72bc508a7783202c96bc15b9e5d05이며, 관련 원본과 현재 설정의 해시는 methodology-assessment.json에 저장했다.

AgentLaboratory의 클래스 및 YAML 누락값 기본 설정은 MLE 3, Paper 5, 단계 허용 100, 문헌 5다(ai_lab_repo.py:20, 686–691). README가 권장하는 MATH_agentlab.yaml은 MLE 3, Paper 1, 문헌 5를 사용한다(README.md:86; YAML:19,26,28). 현재 파일럿 B는 MLE 1, Paper 0, 단계 4, 문헌 1이다. 원본 함수와 전체 단계가 실행된다는 사실과 기본 설정을 재현한다는 주장은 구분해야 한다.

현재 설정은 초기 MLE 코드 생성 뒤 추가 solve를 전혀 호출하지 않는다(ai_lab_repo.py:321–324). 원본 solve는 min_gen_trials=1이어도 0부터 세는 num_attempts 비교 때문에 최소 두 유효 후보 시도를 수행한다(mlesolver.py:276–305). 보고서 초기 아홉 단계와 최종 리뷰는 수행하지만 Paper solve 수정은 호출하지 않는다(ai_lab_repo.py:253–255). 원본 Paper solve는 같은 이유로 최소 세 유효 수정 시도를 수행한다(papersolver.py:269–294).

같은 모델·medium·공개 데이터·문헌·도구 권한과 51 모델 요청/51 CPU 실행 상한은 통제됐다. 하지만 B 실험 반복이 사전에 제거된 반면 C는 그 자원을 자율 실험에 재배분한다. 따라서 현재 결과는 **명시된 최소 단계 원본 어댑터와 C의 비교**이며, 원본 권장 반복 정책보다 우수하다는 일반 결론이나 단계 자원 배분과 분리된 설계 효과를 뒷받침하지 않는다. 보고서 필수 내용 게이트도 인간 평가에 의한 보고서 품질 동등성을 의미하지 않는다. A는 미실행이므로 모델 교체 효과도 실증 추정할 수 없다.

첫 linear-seed7 B는 실제 모델 26회와 CPU 2회를 완료했다. CPU 두 번은 한 구성의 반복이며 별도 고정 검증이 유효했다. 이 수치는 첫 개발 단위 관찰이고 전체 파일럿 결과나 개선 주장이 아니다. 원본 보고서는 이 중복과 미실행 후보를 명시했다.

후속 별도 사전 등록에서는 적어도 권장 solver 3/1을 포함하는 것이 타당하다. 첫 정상 경로 26 요청을 기준으로 원본 MLE solve 두 번의 최소 generation/judge 8, 채택 시 reflection 최대 2, Paper solve 한 번의 최소 generation/judge 6을 더하면 정상 경로 예상은 40–42 요청이다. 이는 코드에 근거한 **미실행 자원 계산**이며 상한이 아니다. 내부 while 재시도·수리·판정 파싱 실패가 추가 요청을 발생시키므로 전역 자원 영수증을 계속 적용해야 한다. 문헌 5나 constructor Paper 5까지 복원하려면 동일하게 확장한 B/C 공통 상한을 별도 등록해야 할 수 있다.

개발 자료에서 권장 3/1과 필요하면 과제에 적합한 더 강한 MLE 4/1의 민감도를 검토하고, 최종 평가 전에 B 정책을 고정한다. 기존 파일럿의 기준·산출물·실행은 유지하며, 관찰한 과제는 개발 자료로 남긴다. 최종 과제의 숨겨진 정답을 정책 선정에 사용하지 않는다.
