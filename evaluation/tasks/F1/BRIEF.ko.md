# F1: 가중 CSV 측정 요약

`solution.py`의 `summarize(rows)`를 고쳐 실제 측정 CSV를 요약한다. `rows`는
`csv.DictReader`가 읽은 문자열 사전 목록이며 입력을 변경하지 않는다.

`group`은 양끝 공백을 제거한다. 빈 그룹, 파싱할 수 없는 숫자, 결측,
NaN/무한대, 0 이하 가중치는 거부한다. 유효한 행의 그룹별 유효 행 수,
가중치 합, 가중 평균, 가중 모집단 분산을 반환한다. 분산은
`sum(w * (x - mean)**2) / sum(w)`이다. 큰 공통 오프셋의 작은 편차도 보존한다.

반환 형식: `{"groups":{"그룹":{"count":정수,"weight":숫자,"mean":숫자,"variance":숫자}},"rejected":정수}`.
유효한 행이 없으면 groups는 빈 사전이다. 다른 필드를 추가하지 않는다.
표준 라이브러리만 사용한다. 공개 input.csv 외의 입력에서도 같은 정책이어야 한다.

과제 지표는 owner 고정 검증기의 `pass_rate`이며 성공 기준은 1.0이다.
숫자는 절대오차 1e-8과 기준값의 double 정밀도 두 단계까지 허용한다.
평가 사례·평가기 구현·다른 조건의 답안은 읽지 않는다. 이 규약은 OS 보안 격리가 아니다.
초기 코드에는 의도적으로 결측 정책과 분산 계산에 결함이 있다.
